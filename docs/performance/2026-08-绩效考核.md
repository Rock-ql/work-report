# 肖磊 · 2026年8月绩效考核

## 1. 项目交付及时率（25%）

8 月完成商城 2.0 全功能 smoke 发版及商城前后端发版，推进组织权限下放从需求评审、方案设计到前后端开发、部署和提测，完成相关测试用例执行。同步上线首页设备类型分布时间筛选、设备按手机号查询与导出等功能，并完成多商城集成方案设计与宣讲，为后续业务迭代做好准备。

## 2. 代码交付质量合格率（20%）

8 月重点完善组织权限与商城核心模块的代码质量，重构组织下放后端接口并与旧接口隔离，细化角色与组织权限边界，统一授权可见范围。补充组织编码全局唯一校验，兼容历史组织类型为空、多条有效授权记录等场景；通过返利结算 smoke 测试、支付联调验证及组织权限功能测试，持续改进边界处理和业务逻辑的健壮性。

## 3. 线上问题修复闭环率（20%）

8 月持续响应商城、管家及全局搜索的问题反馈，修复返利手动发放编号重复、返利管理权限点过于集中、脏数据导致库存回滚等问题并上线。同步处理组织历史数据展示、角色权限查询、设备激活时间及 ICCID 展示异常，结合开发修复、联调验证和发布跟进推进问题处理，保障核心业务正常运行。

## 4. 产品性能达标率（15%）

8 月围绕组织查询与权限鉴权开展优化，解耦组织角色权限分配鉴权，优化接口响应和组织树查询，重构角色员工轻量分页接口。通过轻量化查询及权限逻辑梳理，改善组织管理、角色分配等高频操作的处理效率，提升系统使用体验。

## 5. 专利类（加分）

本月不申报专利及软件著作权加分。

## 6. 技术经验分享（加分）

8 月完成多商城开发方案宣讲与技术讨论，输出组织权限边界规则总纲及组织重构开发文档，沉淀角色、组织和系统维度的权限设计经验。结合项目开发协助同事熟悉业务与代码结构，促进方案理解、技术协作及知识传递。

## 7. 项目流程规范类（减分）

8 月围绕组织重构、组织认证及经销商认证等需求开展评审与方案沟通，完成开发文档、权限边界规则和提测材料整理，配合测试用例执行与缺陷跟进。线下数据导入与业务方确认数据准确性，商城迭代通过功能演示及需求沟通明确后续方向，落实需求评审、开发协作、提测和交付等流程要求。
